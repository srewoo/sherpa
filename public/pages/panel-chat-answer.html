Where do I find the tenant ID for API calls?
Answered with Chrome built-in model

Your tenant ID is shown under Admin → Organization → General, in the field labelled Tenant ID (a 26-character identifier).1 It is also returned as the x-nw-tenant header on every authenticated API response.2

How do I rotate an API key without breaking live integrations?
Answered with Chrome built-in model (Gemini Nano) · on-device

Northwind supports overlapping keys so you can rotate with zero downtime. Follow these steps:1

  1. In Admin → API Keys, select the key you want to rotate and choose Generate successor. The original key stays active.1
  2. Deploy the new key to your integrations. Both the old and new key are accepted during the overlap window.1
  3. Confirm traffic has moved: the key's Last used timestamp updates within ~60 seconds of a live call.2
  4. Once the old key shows no recent use, click Revoke predecessor to close the window.1

The default overlap window is 30 days; you can shorten it per key but not extend it beyond 90 days.3
